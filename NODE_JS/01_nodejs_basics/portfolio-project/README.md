
# Personal Portfolio Website

## Description

A simple Personal Portfolio Website built using Node.js HTTP module, HTML, and CSS.

This project contains Home, About, and Contact pages.


## Technologies Used

- Node.js
- HTTP Module
- File System (fs) Module
- HTML5
- CSS3


## Features

- Home page
- About page
- Contact page
- Navigation between pages
- Node.js HTTP server
- HTML and CSS file serving using fs module



## How to Run

1. Install Node.js.
2. Open the project folder in terminal.
3. Run the following command:

   node 13_http.js

4. Open your browser and visit:

   http://localhost:3000
